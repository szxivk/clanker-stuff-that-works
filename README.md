# clanker-stuff-that-works

A personal collection of AI agent tools, prompts, skills, and experiments.

See [`.pi/README.md`](.pi/README.md) for Pi setup, local extensions, and package links.

[`.config/agents/AGENTS.md`](.config/agents/AGENTS.md) is a copy of my global agent instructions. My global source lives at `~/.config/agents/AGENTS.md`. Each AI harness's global instruction file should symlink to that source so all harnesses use the same instructions.
